# LLMHub

多模型聚合聊天 Android 应用

## 简介
LLMHub 是一款多模型聚合聊天 Android 应用，支持统一管理多家大语言模型厂商的 API Key、配置模型参数、进行对话聊天，并提供用量统计与 Web 登录对账功能。

## 技术栈
- Kotlin + Jetpack Compose Material3
- Hilt (DI) + Room (DB)
- OkHttp SSE + Kotlinx Serialization
- Gradle 8.9 + AGP 8.5.2 + compileSdk 36
